# DNA Translator

A browser tool that validates a DNA sequence, transcribes it to mRNA and translates it into a protein.
Plain HTML, CSS and JavaScript. No framework, no build step, no server, no API, no internet needed.

## Files
- index.html  page structure
- style.css   responsive styling, light and dark mode
- script.js   validation, transcription, translation
- README.md   this file

## Run on Windows
1. Put all four files in one folder, for example C:\Users\you\dna-translator
2. Double-click index.html. It opens in your browser.

Optional local server (only if you want one): open the folder in VS Code, install the Live Server extension, right-click index.html and choose Open with Live Server. Or run `python -m http.server 8000` in the folder and visit http://localhost:8000

## Host for free (GitHub Pages)
1. Create a GitHub account and a new public repository named dna-translator.
2. Choose Add file, then Upload files, drag in the files, and commit.
3. Go to Settings, then Pages. Under Branch select main and folder / (root), then Save.
4. After about a minute the site is live at https://YOUR-USERNAME.github.io/dna-translator/

Faster alternative: drag the folder onto https://app.netlify.com/drop
